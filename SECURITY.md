# Security Policy

## Supported version

Security reports are reviewed for the current v1 code on the default branch and the public deployment. Historical benchmark experiments are not maintained as separate release branches.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Thazg/knowledge-intelligence-platform/security/advisories) to share a potential vulnerability with the maintainer. Do not include exploit details, credentials, or private data in a public issue or pull request.

Include the affected component and version or commit, steps to reproduce, the expected and observed behavior, and the potential impact. A minimal proof of concept is helpful when it can be shared safely. The maintainer will review the report privately and coordinate a fix or disclosure as appropriate.
